## Commit-Message Integration Notes

- Context precedence is public DataKey only: commit control; workflow UI text/document; workflow included changes then selected/all changes; included unversioned files; public VCS revision.
- `DiffTooBigException` extends `ProcessCanceledException` in IntelliJ 2025.3, so Git context collection catches it before cancellation and treats it as a filtered file.
- `ContentRevision` exposes complete text rather than a streaming API. Current/revision files therefore have an additional 2 MiB virtual-file guard where size metadata is available; emitted diff remains capped at 12K.
- Gradle 2.16 does not expose the IntelliJ 2025.3 base Velocity module through its bundled-module index. The build uses the IDE-shipped `lib/module-intellij.libraries.velocity.jar` as the documented `bundledLibrary` workaround.
- IDEA 2025.3 supplies a patched coroutine runtime. External Kotlin/coroutine runtime artifacts are excluded from the test runtime, and `instrumentTestCode` runs after `instrumentCode` to avoid the shared Ant instrumenter race.
- Automated verification covers public Action IDs/order, both toolbar places, Keymap conflicts, DataKey precedence, stale writeback, list/settings lifecycles, PasswordSafe failure handling, provider protocols/fallbacks/UTF-8/timeout, and context privacy/caps. The non-modal Commit ToolWindow and traditional Commit Dialog both passed live IDEA visual acceptance; exact evidence and intentional external-provider skips are recorded in [verify.md](../specs/260715/1208-commit-message-helper-integration/verify.md).

Reusable failure routes are indexed in [error memory](error-memory/README.md); exact task acceptance evidence is owned by [verify.md](../specs/260715/1208-commit-message-helper-integration/verify.md).
