## Commit-Message Integration Notes

- Context precedence is public DataKey only: commit control; workflow UI text/document; workflow included changes then selected/all changes; included unversioned files; public VCS revision.
- Original upstream defaults are restored: Default OpenAI-compatible Profile at `https://api.openai.com/v1`, temperature `0.5`, English, streaming enabled, Smart Echo/reasoning disabled, upstream Velocity template, and conventional type descriptions. Adapted upstream default text is covered by the packaged Apache-2.0 notice/license.
- Test Connection first fetches models and only then sends a non-streaming, non-reasoning, temperature-zero inference capped at 8 output tokens when a model is selected. Blank-model Test stops after discovery. Fetch/Test buttons expose immediate status and request-local cancellation; Apply, Reset, dialog close, Profile change, and dispose cancel current work.
- Custom styles can derive their effective prompt from the natural-language description, optionally own a Velocity template, and use an AI proposal flow that never sends Git/source context. Generate, Format, Smart Echo, and JSON repair all retain the effective style prompt.
- Format's service contract accepts only current commit text, a 4K-capped one-off instruction, Profile, template/style snapshot, and indicator. It cannot access changes/revision, never invokes Git context collection, reports no filtered files, and retains the one-off instruction across controlled JSON repair. The 16K current-text and 8K template caps remain explicit.
- Preview refinement prepares the exact primary prompt envelope before either prompt optimization or Commit modification. Confirmation exposes only prompt fields; Provider credentials are transmitted separately for authentication. Successful history stores raw, AI-optimized, and confirmed instructions plus both prompt envelopes in dialog memory. Repair carries forward the confirmed bounded source request before appending invalid output, preventing loss of the current Commit/template facts.
- `DiffTooBigException` extends `ProcessCanceledException` in IntelliJ 2025.3, so Git context collection catches it before cancellation and treats it as a filtered file.
- `ContentRevision` exposes complete text rather than a streaming API. Current/revision files therefore have an additional 2 MiB virtual-file guard where size metadata is available; emitted diff remains capped at 12K.
- Gradle 2.16 does not expose the IntelliJ 2025.3 base Velocity module through its bundled-module index. The build uses the IDE-shipped `lib/module-intellij.libraries.velocity.jar` as the documented `bundledLibrary` workaround.
- IDEA 2025.3 supplies a patched coroutine runtime. External Kotlin/coroutine runtime artifacts are excluded from the test runtime, and `instrumentTestCode` runs after `instrumentCode` to avoid the shared Ant instrumenter race.
- Automated verification additionally covers common-data CAS across two JVMs, same-revision quarantine recovery, bounded ancestry conflicts, project shared/private conflict behavior and rollback, credential transactions, isolated Codex version probing, stable protocol payloads, mandatory capability negotiation, exact isolation, bounded model pagination, durable generation repair/CAS winner adoption/future-schema rejection, cancellation, malformed/unknown/tool event rejection, process-tree termination, and no credential/account/consent synchronization. The full r7 suite contains 259 tests; exact evidence and intentional external-provider skips are recorded in [verify.md](../specs/260715/1208-commit-message-helper-integration/verify.md).
- Environment Actions / Codex Chat adds schema migration/order/project-selection, real cross-process CAS, one-shot command construction, true multi-turn/approval/interrupt protocol, native Commit draft, Configurable transaction, descriptor/localization and process-tree cancellation coverage. The current suite contains 29 suites / 309 tests; IntelliJ 2026.1.4 local fake-runtime evidence and intentionally skipped real credentials/inference/commit are recorded in [its verification record](../specs/260731/1720-environment-actions-codex-chat/verify.md).
